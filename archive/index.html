How AI Maintains This Website

Zero-HTML, Schema-driven Architecture

1. Zero-HTML Trip Engine (`trip.html?id=...`)

Instead of generating huge HTML files, you or your AI assistant simply creates a structured JSON file at data/trips/<slug>.json following trip.schema.json. The website automatically renders the interactive Leaflet map, day schedule, packing list, and driver cards.

2. In-Browser "AI Copilot"

Click the AI Copilot button at any time. Paste unstructured WhatsApp itineraries, flight tickets, or hotel emails. Powered by Gemini 2.5 Flash, it converts your text into a live interactive trip in 3 seconds!

3. Coding AI Agent Playbook (`AGENTS.md`)

When you pair-program with coding assistants (like Antigravity, Cursor, Copilot), the AI reads AGENTS.md in this repository to create and register trips automatically with 100% adherence to design guidelines.
